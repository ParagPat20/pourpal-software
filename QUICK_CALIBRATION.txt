📍 WHERE TO CHANGE IT:
   File: app.py
   Line: ~22
   Variable: SECONDS_PER_ML = 1.3

🧮 HOW TO CALCULATE:
   1. Run pump for 10 seconds
   2. Measure ml dispensed
   3. SECONDS_PER_ML = 10 / ml_dispensed

📊 CURRENT SETTING: 1.3 seconds per ml
   • 1ml  = 1.3 seconds
   • 30ml = 39 seconds
   • 45ml = 58.5 seconds
   • 60ml = 78 seconds

🔧 COMMON ADJUSTMENTS:

   TOO MUCH LIQUID?    → INCREASE value
   Example: Change 1.3 to 1.5

   TOO LITTLE LIQUID?  → DECREASE value
   Example: Change 1.3 to 1.1

💡 QUICK TEST:
   • Request 60ml drink
   • Measure actual output
   • If you got 52ml: New value = 1.3 × (60/52) = 1.5
   • If you got 70ml: New value = 1.3 × (60/70) = 1.1

📝 AFTER CHANGING:
   • Save app.py
   • Restart the app
   • Check console for calibration info
